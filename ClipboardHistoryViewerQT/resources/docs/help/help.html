Clipboard History Viewer QT

Text and image clipboard history viewer for Linux / X11


Overview

Clipboard History Viewer QT is a lightweight Qt application that monitors the system clipboard and keeps a history of recent text and image entries. You can quickly switch between previous clipboard contents, preview them, and restore any entry to the clipboard with a single click.

The application is designed for X11 environments and supports window manager hints for sticky windows and always-on-top behaviour.

Main Window

The main window consists of three primary areas:

  1. Preview area – a read-only text/image view that shows the currently selected clipboard entry.
  2. History combo box – a drop-down list of recent clipboard items (text or images).
  3. Button bar – controls for managing the history and opening dialogs.

History Combo Box

  • Each new unique clipboard item is added to the top of the list.
  • Long text entries are truncated in the list for readability (middle ellipsis).
  • Image entries are shown with a generated name such as Image-1, Image-2, etc., or the original file name when the clipboard contains a file URL.
  • The maximum number of stored entries is limited (default 32). Older entries are automatically removed when the limit is reached.
  • Selecting an entry from the list restores it to both the preview area and the system clipboard.

Supported Clipboard Content

  • Plain text – any text placed on the clipboard.
  • Images – images copied directly or via file URLs that can be loaded as images.
  • File URLs – when a local file path or URL is on the clipboard, the application attempts to load it as an image; if that fails it is treated as text.

Buttons

Clear Removes the currently selected entry from the history list and updates the preview / clipboard to the next remaining item. Clear All Removes every entry from the history and clears the preview area. Prefs Opens the Preferences dialog (see below). About Shows the About dialog with version information, licence, credits and a link to the project page. Quit Exits the application. If “Save History” is enabled, the current text history is written to the settings file.

Preferences

The Preferences dialog provides three options:

Option Description
Save History When enabled, the list of text clipboard entries is saved on exit and restored the next time the application starts. Image data is not persisted.
Sticky Makes the main window “sticky” (visible on all virtual desktops / workspaces) using the _NET_WM_STATE_STICKY window manager hint.
On Top Keeps the main window above other windows using the _NET_WM_STATE_ABOVE window manager hint.
Max Clips Sets the maxuimum number of clips.
Changes to Sticky, On Top, and Max Clips take effect immediately after you accept the Preferences dialog. Geometry (window size and position) is always remembered between sessions.

Behaviour Notes

  • The application listens to the system clipboard’s dataChanged signal and reacts automatically when new content appears.
  • Duplicate text or identical image data is not added again if it is already present in the history.
  • When restoring an entry, signals are temporarily blocked so that the restore action itself does not create a new history item.
  • Window state (sticky / on-top) is applied via X11 properties and therefore requires a compatible window manager.
